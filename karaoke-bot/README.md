# 🎤 Karaoke Bot — Telegram-бот для создания караоке-видео

[![Docker](https://img.shields.io/badge/docker-%230db7ed.svg?style=for-the-badge&logo=docker&logoColor=white)](https://www.docker.com/)
[![Python](https://img.shields.io/badge/python-3.10-blue.svg)](https://www.python.org/)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)

**Karaoke Bot** — это Telegram-бот, который автоматически превращает любую аудиозапись (или видео) в караоке-ролик с подсвечивающимися субтитрами.  
Всё, что нужно — отправить файл боту, и через пару минут вы получите ссылку на готовое видео в облаке.

---

## 📝 Возможности

- Поддержка любых аудиоформатов (MP3, WAV, M4A, OGG, FLAC, AAC, голосовые сообщения) и видео (MP4, AVI, MOV, MKV).
- Разделение вокала и инструментала с помощью **Demucs**.
- Распознавание текста с точными таймкодами слов через **Whisper Large-v3**.
- Наложение субтитров в стиле караоке (подсветка слова) на чёрный фон.
- Готовое видео загружается в облачное хранилище **MinIO** и доступно по постоянной ссылке.
- Полностью контейнеризирован (Docker + docker-compose), готов к развёртыванию на GPU-сервере.

---

## 🚀 Как это работает (для пользователей)

1. Найдите бота в Telegram по ссылке (или запустите свою копию — см. раздел «Установка»).
2. Отправьте боту аудиофайл (или видео — звуковая дорожка будет извлечена автоматически).
3. Бот пришлёт статус обработки:
   - «Нормализация аудио…»
   - «Разделение на вокал и минусовку…»
   - «Распознавание текста…»
   - «Создание видео…»
4. Готово! Вы получите ссылку на видео, например:  
   `https://mykaraokebot.win/karaoke/ваше_видео.mp4`

> **Важно:** бот обрабатывает **англоязычные** аудио (поддержка других языков не гарантируется).  
> Максимальный размер файла — **50 МБ**, длительность — **до 10 минут**.

## 📦 Установка и запуск (для разработчиков и администраторов)

### Требования
- Сервер с **GPU** (NVIDIA) и установленными драйверами CUDA (рекомендуется).
- **Docker** и **docker-compose**.
- (Опционально) Домен и Cloudflare Tunnel для публичного доступа к MinIO.

### Шаг 1. Клонирование репозитория
```bash
git clone https://github.com/uniso-o/karaoke-bot.git
cd karaoke-bot
```

### Шаг 2. Настройка переменных окружения
Скопируйте шаблон и отредактируйте его:
```bash
cp .env.example .env
nano .env
```
##Обязательно укажите:
    BOT_TOKEN — токен вашего Telegram-бота (получить у @BotFather).
    Параметры MinIO (если вы меняете стандартные порты или пароли).
    MINIO_EXTERNAL_URL — внешний URL для доступа к видео (например, https://mykaraokebot.win).
### Шаг 3. Настройка переменных окружения
Скопируйте шаблон и отредактируйте его:
```bash
docker-compose up -d
```
Первый запуск может занять несколько минут — будут загружены модели Demucs и Whisper.

### Шаг 4. Проверка
Бот должен запуститься и ответить на команду /start в Telegram.


### ✅ Таблица переменных окружения
⚙️ Конфигурация (переменные окружения)
| Переменная | Описание | Пример |
|------------|----------|--------|
| `BOT_TOKEN` | Токен Telegram-бота | `123456:ABC-DEF` |
| `MINIO_ROOT_USER` | Логин для MinIO | `minioadmin` |
| `MINIO_ROOT_PASSWORD` | Пароль MinIO | `minioadmin` |
| `MINIO_BUCKET` | Название бакета | `karaoke` |
| `MINIO_ENDPOINT` | Внутренний адрес MinIO | `minio:9000` |
| `MINIO_EXTERNAL_URL` | Публичный URL для ссылок | `https://mykaraokebot.win` |
| `MAX_FILE_SIZE_MB` | Максимальный размер файла (МБ) | `50` |
| `MAX_DURATION_SEC` | Максимальная длительность (сек) | `600` |

Все параметры также можно менять в файле `docker-compose.yml`.

## 🧩 Техническая архитектура (для глубокого погружения)
Проект построен на следующих компонентах:

- **aiogram** — асинхронный фреймворк для Telegram-бота.
- **Demucs (htdemucs)** — нейросеть для разделения аудио на вокал, барабаны, бас и остальное.
- **Whisper Large-v3** — распознавание речи с таймкодами слов (загружается через Hugging Face Transformers).
- **FFmpeg** — обработка аудио (нормализация, удаление тишины, конвертация) и создание видео (чёрный фон, наложение ASS-субтитров).
- **MinIO** — S3-совместимое хранилище для готовых видео.
- **Docker & docker-compose** — контейнеризация и оркестрация.

### Структура репозитория
```
├── bot.py # Основной скрипт бота (обработчики команд, логика)
├── karaoke_utils.py # Утилиты: обработка аудио, разделение, транскрипция, создание видео
├── requirements.txt # Python-зависимости с фиксированными версиями
├── Dockerfile # Сборка образа на базе PyTorch + CUDA
├── docker-compose.yml # Описание сервисов (minio и karaoke-bot)
├── .env.example # Шаблон переменных окружения
└── .gitignore # Исключения для Git
```

### Особенности реализации
- Предварительная загрузка моделей в `Dockerfile` — чтобы первый запуск не тормозил пользователя.
- Использование **ASS-субтитров** с динамической подсветкой слов (тег `\k`), шрифт 100 pt, центрирование.
- Очистка временных файлов после обработки и graceful shutdown.
- Для публикации видео используется MinIO с публичной политикой бакета.

## 📥 Поддерживаемые форматы и ограничения

| Тип | Форматы |
|-----|---------|
| **Аудио** | MP3, WAV, M4A, OGG, FLAC, AAC, OGG Opus (голосовые сообщения) |
| **Видео** | MP4, AVI, MOV, MKV (извлекается аудиодорожка) |

**Ограничения:**
- Максимальный размер файла: **50 МБ** (ограничение Telegram).
- Максимальная длительность: **10 минут** (ограничение GPU-времени).
- Язык: **английский** (Whisper принудительно устанавливает `language='en'`).
- Результат для других языков не гарантируется.

## 🛠 Развёртывание на Vast.ai (пример)

Проект успешно протестирован на GPU-инстансах Vast.ai с Ubuntu 22.04.

1. Арендуйте инстанс с GPU (минимум 8 ГБ видеопамяти).
2. Установите Docker и docker-compose (можно через скрипт).
3. Клонируйте репозиторий, настройте `.env`.
4. Запустите `docker-compose up -d`.
5. Настройте **Cloudflare Tunnel** для публикации MinIO по HTTPS (если нужен внешний доступ).
6. Добавьте systemd-сервис для автозапуска контейнеров после перезагрузки.
